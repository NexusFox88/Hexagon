Scope: the existing `#sandboxes` connections page and application-owned dialogs opened from that route. ## Implementation

- `sandbox-pilot.css` applies scoped typography, spacing, square controls, flat surfaces, fine row separators and column budgets. Existing render/API handlers were not changed for this task.
- `sandbox-pilot-tokens.css` is generated by `node tooling/generate-console-pilot-tokens.mjs` from the portable JSON; marketing values are excluded.
- Funnel Display, Inter and IBM Plex Mono 400/500 are self-hosted with their OFL licenses. No runtime third-party font requests.
- Shared sidebar, theme variables and other route styles remain unchanged. Two-line records preserve the 64px readability budget; narrow controls use the 44px touch token.
- The pilot is documented as an explicit scoped exception in `docs/console-design.md`.

## Review iterations and limits

The initial screenshot exposed wrapped credential text and a clipped mobile refresh label; the credential column budget and mobile icon-only refresh presentation were corrected, preserving its accessible name. Final table widths also keep the action column visible at 1440px.

Early browser harness attempts were not passes: a non-ref snapshot root was rejected, viewport zoom made requested and actual sizes differ, stylesheet disabling/re-enabling briefly sampled fallback styles, and pointer actions during emulated viewport/scroll changes did not reliably activate their target. Final measurements asserted actual viewport width and loaded title font; keyboard actions explicitly targeted the existing controls. The final JSON files represent successful reruns, not those attempts.

No 200% zoom audit, full provider/editor variant matrix or live credential CRUD was run for this scoped style change. Existing permissions, mutations and cloud execution behavior are not re-certified by these presentation checks.
