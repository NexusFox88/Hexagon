# Console connection CRUD and archived Fleet browser acceptance

Implemented `/console/` with authenticated connection forms and Fleet. Static assets use same-origin CSP, no inline script, no external fonts or scripts. Untrusted display values use DOM text content. API tokens stay in page memory; credential fields clear after save/close. Backend adds authenticated `/fleet` and tenant-scoped `/sessions/:id/runs`, excluding lease and secret-reference fields. Closed Sessions show stopped Runtime state and retain destroyed sandbox history.
