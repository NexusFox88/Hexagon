## Implementation

- Registered Instabox Connector with native HTTPS lifecycle, pagination/metadata reconciliation, create/delete idempotency, durable asynchronous delete handles, binary files with SHA-256 verification, bounded foreground/background commands, native TTL request plus control-plane expiry.
- Runtime/HTTP preview uses short-lived SSH certificates and strict HTTPS-issued host-CA trust with native TCP forwarding. It opens no public cloud ports. Provider credentials stay outside the guest; create disables personal Vault and native Secret delivery explicitly. Existing protected credentials use Hexagon's external proxy; this does not claim native Instabox Org Secret administration.
- Console supports both languages and the shared CRUD/verify/enable/disable/Secret-reference flows. API/SDK bindings use the existing provider-independent interfaces.
- One-machine accounts can run the unchanged assertion set serially with `HEXAGON_SERIAL_SDKS=1`: Python continues the TS Session, verifies cancellation and closes it before provisioning its independent Session; TypeScript continues the Python Session. Original concurrent mode remains the default.
- Capability boundaries and official API sources: [integration guide](../../docs/instabox.md).
