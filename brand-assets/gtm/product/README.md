# Product evidence library

Seven editorial stories are defined in `provenance.json`. They use live Console captures made on November 20, 2026 and the earlier README captures from the same date. No cloud Run was created for GTM production. Original screenshot pixels have not been changed; detail variants explicitly crop the navigation/margins and keep the source capture available.

## Story scope

1. **First Session:** API Playground configuration and REST visibility. It is a configuration view, not a new execution.
2. **Initialization:** retained definition and JSON inspection. It does not certify future quota or readiness.
3. **Tool access:** actual historical DeepWiki MCP call history. It is not evidence of OAuth signup or a write-approval flow.
4. **Continuation:** second turn of a historical E2B/OpenCode Session. File-integrity and pause claims require the linked dated acceptance evidence; they are not inferred from the text of a model response.
5. **Harnesses:** real catalog templates and recipes. These are not a universal provider compatibility promise.
6. **Artifacts:** a retained Vercel/Pi task and download controls after closure. No new byte verification was performed for this kit.
7. **Observability:** existing task, response and execution progress.

The extra `captures/tools.png` shows the configured Tool list and saved-credential masking. It is supplementary context, not an eighth executed journey.

## Captures and recording

The capture environment used the real local Console in English and dark mode. Test-generated names, markers and non-secret IDs remain visible. No raw key values are visible in the reviewed screenshots or sampled recording frames. Configuration, metrics, task text and completion states were not rewritten for presentation.

`tool-session-walkthrough.mp4` is a sampled recording of actual browser interaction: Call history → Assigned Sessions → Call history → retained Session → Initialization. It contains 24 captured browser frames over approximately ten seconds, encoded as a 1280 x 720 / 24 fps video. It includes actual loading states. It is deliberately not described as a smooth 24 fps source recording or a live cloud acceptance run. There is no audio. Private intermediate frames are under `.local/gtm-recording/sampled`.

Do not use this footage to claim a new Sandbox was created, a credential was authorized, compute was paused, or an Artifact hash was verified during the recording. New end-to-end demonstrations require a separate actual execution and a new evidence record.
